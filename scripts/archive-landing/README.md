# archive.indianliberals.in landing page

The bucket's front door is rendered live by the Worker in `apps/archive-root`
(`src/landing.js`), from two sources:

- `https://indianliberals.in/api/archive-stats.json`, which the site computes
  from its content on every deploy (`apps/site/src/pages/api/archive-stats.json.ts`):
  works, pages, PDFs and covers, the earliest and latest year, the decade
  histogram, the longest work, the most-published voices, languages, the
  largest runs, and the people and institutions counts;
- the bucket itself, listed once an hour per isolate, for how many bytes the
  PDFs come to.

Nothing is regenerated by hand any more. The wording between the numbers lives
in `landing.js`; change it there and `npx wrangler deploy` from `apps/archive-root`.

The object `index.html` in the bucket is the fallback the Worker serves if the
figures cannot be fetched; it is the last static render (July 2026) and is
stale by design. `og/archive.jpg` (from `archive.jpg` here) is the social card:

```sh
npx wrangler r2 object put indianliberals-archive/og/archive.jpg \
  --file scripts/archive-landing/archive.jpg \
  --content-type "image/jpeg" --remote
```
